Neovim Cheat Sheet

Übersicht über die konfigurierte gemeinsame Neovim-Basis und das Go-spezifische Setup.

Leader = Leertaste LocalLeader = , nvim = allgemeines Setup nvim_go = Go-Setup

Dateien & Suche

Telescope

  • Leaderff
    Dateien suchen
  • Leaderfg
    Volltextsuche Verwendet Telescope live_grep.
  • Leaderfr
    Zuletzt verwendete Dateien

Telescope Navigation

  • Esc
    Telescope schließen
  • Ctrlj
    Nächsten Eintrag auswählen
  • Ctrlk
    Vorherigen Eintrag auswählen

File Chooser

  • Ctrln
    Neue Datei anlegen Relative Pfade beziehen sich auf das aktuelle Telescope-Arbeitsverzeichnis.
  • Ctrlr
    Ausgewählte Datei umbenennen Relative Zielpfade beziehen sich auf das Verzeichnis der ausgewählten Datei.
  • Ctrld
    Ausgewählte Datei löschen Vor dem Löschen wird eine Bestätigung verlangt. Geöffnete Dateien werden nicht gelöscht.

Completion & Snippets

Insert Mode

  • CtrlSpace
    Completion manuell öffnen
  • Enter
    Completion bestätigen Der aktuell ausgewählte Eintrag wird übernommen.
  • Tab
    Nächsten Completion-Eintrag auswählen Falls kein Menü offen ist, zum nächsten Snippet-Feld springen.
  • ShiftTab
    Vorherigen Completion-Eintrag auswählen Falls kein Menü offen ist, zum vorherigen Snippet-Feld springen.

Completion-Quelle

  • LSP-Completion über nvim-cmp und cmp-nvim-lsp
  • Snippets verwenden die eingebaute vim.snippet-API
  • Completion-Menü startet ohne automatische Vorauswahl

Terminal

Terminal Mode

  • Esc
    Vom Terminal-Mode in den Normal-Mode wechseln

Single-File Workflow

Dateiverhalten

  • Beim Start ohne geöffnete Datei wird automatisch Telescope geöffnet
  • Es bleibt jeweils nur eine normale Datei als Buffer geöffnet
  • Beim Dateiwechsel wird die vorherige geänderte Datei automatisch gespeichert
  • Nach erfolgreichem Speichern wird der vorherige Buffer geschlossen
  • Schlägt das Speichern fehl, wird zur vorherigen Datei zurückgekehrt
  • Nach dem Schließen der letzten Datei öffnet sich erneut die Dateisuche

Editor-Verhalten

Darstellung

  • Absolute und relative Zeilennummern
  • Aktuelle Zeile wird hervorgehoben
  • Sign Column ist dauerhaft sichtbar
  • Zeilenumbruch ist deaktiviert
  • Mindestens acht Zeilen bzw. Spalten Abstand zum Fensterrand beim Scrollen
  • True-Color-Unterstützung ist aktiviert
  • TokyoNight im Stil night
  • Globale Lualine-Statusleiste

Bearbeitung

  • Standard-Einrückung: vier Leerzeichen
  • Smart Indent ist aktiviert
  • System-Clipboard über unnamedplus
  • Undo-History wird dauerhaft gespeichert
  • Swap- und Backup-Dateien sind deaktiviert
  • Versteckte Buffer sind erlaubt
  • Mouse-Support ist deaktiviert
  • Yanks werden kurz visuell hervorgehoben

Suche & Fenster

  • Suche ignoriert Groß-/Kleinschreibung standardmäßig
  • Großbuchstaben im Suchbegriff aktivieren automatisch Case-Sensitivity
  • Inkrementelle Suche und Suchtreffer-Hervorhebung sind aktiviert
  • Vertikale Splits öffnen rechts
  • Horizontale Splits öffnen unten

Treesitter

Gemeinsame Basis

  • Lua-Parser wird über die gemeinsame Konfiguration bereitgestellt
  • Treesitter-Highlighting startet automatisch für verfügbare Parser
  • Treesitter-basierte Einrückung wird automatisch aktiviert

Go Setup

Start

  • nvim_go
    Go-spezialisiertes Neovim starten Alias für NVIM_APPNAME=nvim-go nvim.

gopls

  • Gemeinsame LSP-Hotkeys und Completion
  • Inlay Hints sind aktiviert
  • gofumpt-Formatierung ist aktiviert
  • Go-Dateien werden vor dem Speichern automatisch über gopls formatiert
  • staticcheck ist aktiviert
  • Analyse ungenutzter Parameter
  • Shadowing-Analyse
  • Nilness-Analyse
  • Analyse ungenutzter Schreibzugriffe

Go Inlay Hints

  • Variablentypen bei Zuweisungen
  • Felder in Composite Literals
  • Typen von Composite Literals
  • Konstantenwerte
  • Function Type Parameters
  • Parameternamen
  • Typen von Range-Variablen

Einrückung

  • Das Go-Setup verwendet Tabs statt Leerzeichen
  • Alle sonstigen allgemeinen Optionen stammen aus nvim-common
